# 🛠️ ProTesisat | Acil Servis & Kurumsal Web Arayüzü

![Proje Durumu](https://img.shields.io/badge/Durum-Tamamlandı-success?style=flat-square)
![Lisans](https://img.shields.io/badge/Lisans-MIT-blue?style=flat-square)

Yerel işletmeler (Tesisatçı, Çilingir, Elektrikçi vb.) için geliştirilmiş; **hız, güven ve müşteri dönüşümü (çağrı)** odaklı modern, responsive (mobil uyumlu) web sitesi arayüzü.

## 🚀 Proje Hakkında

Bu proje, acil hizmet sektöründeki işletmelerin dijital varlıklarını güçlendirmek amacıyla tasarlanmıştır. Kullanıcıların acil durumlarda (örneğin su basması) siteye girdiğinde aradıkları "Hemen Ara" veya "WhatsApp" butonlarına en hızlı şekilde ulaşması hedeflenmiştir.

Geleneksel ve karmaşık tasarımların aksine; sade, modern ve eyleme geçiren (Call-to-Action) bir yapı kurgulanmıştır.

## ✨ Öne Çıkan Özellikler

* **📱 %100 Mobil Uyumlu (Responsive):** Telefondan, tabletten ve masaüstünden kusursuz görünüm.
* **⚡ Yüksek Performans:** Framework kullanılmadan, Saf (Pure) **HTML5** ve **CSS3** ile kodlandı. Sayfa yüklenme hızı optimize edildi.
* **🎨 Modern UI/UX Tasarım:**
    * **Parallax Efekti:** Hero bölümünde derinlik algısı.
    * **Sticky Header:** Sayfa kaydırıldığında sabit kalan menü.
    * **Glassmorphism & Gölgeler:** Modern CSS teknikleriyle şık detaylar.
    * **Hover Animasyonları:** Etkileşimli hizmet kartları ve butonlar.
* **📞 Dönüşüm Odaklı:** Stratejik konumlara yerleştirilmiş "Hemen Ara" butonları.
* **🔍 SEO Uyumlu Yapı:** Semantik HTML etiketleri kullanımı.

## 🛠️ Kullanılan Teknolojiler

* **HTML5** (Semantik Yapı)
* **CSS3** (Flexbox, CSS Grid, CSS Variables, Keyframe Animations)
* **FontAwesome** (İkon Seti)
* **Google Fonts** (Poppins Ailesi)

## 💻 Kurulum ve Çalıştırma

Bu proje statik bir web sitesi olduğu için herhangi bir kurulum veya bağımlılık (node_modules vb.) gerektirmez.

1.  Bu repoyu bilgisayarınıza klonlayın:
    ```bash
    git clone [https://github.com/KULLANICIADINIZ/protesisat.git](https://github.com/KULLANICIADINIZ/protesisat.git)
    ```
2.  Klasörün içine girin ve `index.html` dosyasına çift tıklayın.
3.  Tarayıcınızda proje açılacaktır.
